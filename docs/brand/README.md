# Tenace — brand

**Name:** Tenace (Italian for *tenacious*) · **tagline:** *non arrenderti* ("don't give up").

## Mark

A rounded violet square with a white **T** whose bar **rises to the right** (progress)
and an orange **spark** centered above it (the effort that keeps it going — and a head: the T is also a person).

| File | Use |
| --- | --- |
| `tenace-mark.svg` | App icon, favicon, avatar |
| `tenace-mark-512.png` | Stores, PWA, social |
| `tenace-logo-light.svg` | Mark + wordmark on light backgrounds |
| `tenace-logo-dark.svg` | Mark + wordmark on dark backgrounds |

Clear space around the mark: ¼ of its width. Never recolor the spark or rotate the bar.

## Color

| Role | Light | Dark | Use |
| --- | --- | --- | --- |
| Violet (brand) | `#6D3BFF` | `#7B52FF` / text `#B8A2FF` | primary actions, mark, progress |
| Spark | `#FF7A1A` | `#FF8A33` | streaks, badges, celebration |
| Ink | `#17142B` | `#F3F1FA` | text |
| Canvas | `#F6F4FB` | `#0E0C15` | page background |
| Positive | `#14935A` | `#4FD493` | slot paid, payments |
| Negative | `#D2364A` | `#FF8A99` | debt, penalty |

Group tones (cards and avatars): violet, spark, mint, sky, rose, sun, ink — gradients defined in
`apps/web/app/globals.css` (`.tone-*`).

## Type

**Plus Jakarta Sans** — extra-bold for the wordmark and titles, tabular numbers for money.

## Voice

Encouraging, light, a little playful. Talk about what is missing, never shame:
"Falta 1 cota e a semana fecha no zero 💪" — not "Você falhou".
